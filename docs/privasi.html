Kebijakan Privasi CryptoWatch

Terakhir diperbarui: 19 November 2026

CryptoWatch adalah aplikasi informasi harga cryptocurrency untuk tugas mata kuliah Pengembangan Aplikasi Perangkat Bergerak. Aplikasi ini tidak menyediakan jual beli, dompet, atau transaksi keuangan apa pun.

Data yang dikumpulkan

  • Email dan nama saat mendaftar atau masuk dengan Google, disimpan di Firebase Authentication.
  • Daftar koin pantauan yang dipilih sendiri oleh pengguna, disimpan di Cloud Firestore pada dokumen akun pengguna, dan salinan lokal di perangkat.
  • Nama tampilan yang diisi pada halaman Pengaturan, disimpan lokal dan di Cloud Firestore.

Data yang tidak dikumpulkan

CryptoWatch tidak meminta lokasi, kontak, kamera, mikrofon, file, maupun data kesehatan. Tidak ada iklan, tidak ada pelacakan, dan tidak ada penjualan data ke pihak lain.

Pihak ketiga

  • Google Firebase (Authentication dan Cloud Firestore) untuk akun dan sinkronisasi pantauan.
  • CoinGecko API untuk data harga dan logo koin. Permintaan hanya berisi nama koin yang diminta, tanpa data pribadi pengguna.
  • Google Fonts untuk memuat font Inter.

Penyimpanan dan keamanan

Data dikirim lewat koneksi terenkripsi HTTPS. Daftar pantauan hanya bisa dibaca oleh akun yang sedang masuk. Logo koin disimpan sementara (cache) di perangkat agar tidak mengunduh berulang.

Penghapusan data

Akun beserta nama dan daftar pantauan dapat dihapus dari dalam aplikasi: buka Pengaturan, tekan Hapus akun, lalu konfirmasi. Penghapusan langsung berlaku dan tidak dapat dibatalkan. Penjelasan lengkap ada di halaman penghapusan akun.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data anak.

Perubahan kebijakan

Jika kebijakan ini berubah, tanggal di bagian atas halaman akan diperbarui.
